# S Clinics Cairo — Arabic Website Prototype

نموذج موقع عربي أحادي الصفحة لعيادة **S Clinics** في الشيخ زايد. المشروع مبني بـ Next.js وTypeScript، ويستخدم Lenis لتمرير سلس مع احترام إعداد `prefers-reduced-motion`.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## أوامر الجودة والإنتاج

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run start
```

## مصدر المحتوى

بيانات التواصل، الموقع، التخصص، والهوية جُمعت من الصفحات العامة لـ S Clinics ود. عمر محمد ثروت وقت إعداد النموذج. روابط الحجز والخريطة مبنية على البيانات المحفوظة في `data/clinic.ts`، وليست مرتبطة بنظام حجز أو خرائط داخلي.

## تنبيه استخدام الصور

الصور الموجودة في `public/images` نُسخت من منشورات إنستجرام العامة بأعلى دقة ظهرت في الصفحة، للاستخدام داخل نموذج مبدئي خاص فقط. لا يجوز نشر الموقع رسميًا قبل الحصول على موافقة العيادة وأصحاب الحالات الظاهرة في الصور. صورة تهنئة عيد الأضحى غير مستخدمة وغير موجودة داخل المشروع.

### الصور المولّدة بالذكاء الاصطناعي

الصور التالية مولّدة خصيصًا للنموذج وتُستخدم كصور جوّ وهوية بصرية، وليست صورًا حقيقية لمقر S Clinics أو تجهيزاته:

- `public/images/ai/clinic-interior-editorial.png` — صورة الـHero التخيلية.
- `public/images/ai/dental-tools-editorial.png` — صورة تحريرية لقسم الخدمات.
- `public/images/ai/enamel-sculpture-editorial.png` — عمل تجريدي لقسم فلسفة الرعاية.

صورة الطبيب وصور الحالات العلاجية منفصلة ومأخوذة من صفحات إنستجرام العامة، ويظل نشرها الرسمي مشروطًا بالموافقة المذكورة أعلاه.

## المطلوب قبل الإطلاق الرسمي

- موافقة مكتوبة على استخدام صور العيادة والطبيب والحالات.
- الشعار الأصلي بصيغة SVG أو نسخة شفافة عالية الدقة.
- صور أصلية عالية الدقة للطبيب والعيادة.
- رابط Google Maps الرسمي وتأكيد رقم الوحدة أو الغرفة.
- قائمة الخدمات النهائية، مواعيد العمل، المؤهلات المهنية، نص الخصوصية، وآلية الحجز الرسمية.
- مراجعة كل النصوص الطبية والتجارية واعتمادها من العيادة.

## بنية المشروع

- `app/` — الصفحة، التخطيط العام، والستايل.
- `components/` — الهيدر، الحركة، الأسئلة، والعناصر المشتركة.
- `data/clinic.ts` — بيانات العيادة وروابط التواصل.
- `public/images/` — الصور المرجعية عالية الدقة للنموذج.
- `tests/` — اختبارات المحتوى، الحركة، وسلوك قائمة الموبايل.
